# بوابة اللغة العربية – ملحقة الجلفة

بوابة تعليمية موحدة لأساتذة وطلبة تخصص اللغة العربية – التعليم الابتدائي.

## المجموعات
- المجموعة A – المدرج أ
- المجموعة B – المدرج د

لكل مجموعة مساحة مستقلة للمحاضرات والتوقيت والإعلانات والواجبات ومكتبة الموارد، مع إمكانية ربط كل أستاذ بالمجموعة التي يدرّس فيها.

## الحالة الحالية
هذه مرحلة الواجهة التأسيسية (HTML/CSS/JavaScript). لا يوجد حتى الآن نظام تسجيل دخول حقيقي أو قاعدة بيانات أو رفع ملفات. يجب إعداد المصادقة والصلاحيات والتخزين قبل استخدام الموقع فعلياً.
